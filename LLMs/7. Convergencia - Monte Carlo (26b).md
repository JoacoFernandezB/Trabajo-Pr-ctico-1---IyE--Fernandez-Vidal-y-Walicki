Convergencia casi segura

\mathbb{P}\left(\lim_{n \to \infty}

X_n = X\right) = 1

Una sucesión de variables aleatorias Xn, converge de forma casi segura a
la variable aleatoria X si se cumple:

X_n \xrightarrow[]{as} X

Convergen  aquellas  sucesiones  que  alcanzan  el  valor  límite  para  todas  las
posibles  realizaciones,  excepto  las  que  tienen  una  probabilidad  nula  de
ocurrir.

Esto implica que toda secuencia Xn posible, construida a partir del espacio

de  eventos  𝛺,  converge  a  X  con  probabilidad  1,  excepto  un  conjunto  de

secuencias cuyas realizaciones tienen probabilidad 0.
